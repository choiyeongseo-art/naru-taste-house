# 나루 취향방 그래픽 방향

2026-10-20. 사용자가 제공한 팔레트와 나루 얼굴을 기준으로 제작했다.

## 팔레트

스카이 `#D6F6FD`, 크림 `#FFF9DC`, 민트 `#D2FAD3`, 라일락 `#ECD7FF`, 핑크 `#FFD7F2`.
글자는 읽기 쉬운 회청색 `#536A7B`를 사용한다. 진한 원색과 광택 효과를 피한다.

## 인테리어와 장소

- 섬세한 실루엣과 선화를 유지하고, 내부는 기본색과 넓은 그림자 한 색으로 채운다.
- 하얀 반사광, 번들거리는 재질, 빛 번짐을 추가하지 않는다.
- 방 배경 1종, 가구 9종, 부산 장소 분위기 6종을 각각 별도 이미지로 생성했다.
- [파니하우스](https://vidkidz.tistory.com/1194)는 열린 대각선 방과 작은 가구의 생활감을 참고했다.
- 치비/미니캐릭터/스티커/아크릴키링/alt cartoon/Y2K 검색은 비례와 선화·장식 방향을 정하는 참고로 사용했다.
- 사용자가 첨부한 외부 게임 이미지의 캐릭터나 가구 디자인은 사용하지 않았다.
- 장소 그림은 실제 건물·매장·동선의 재현이나 사진이 아닌 창작 분위기 일러스트다.

## 플레이어 아바타

- 기본 아바타는 파란 장발, 흰 민소매와 불투명한 흰 반바지, 로우폴리 3D 렌더 스타일이다.
- 얼굴은 사용자가 제공한 나루의 세로형 검은 테두리 눈과 작은 곡선 입을 기준으로 생성했다.
- 핑크 원피스, 라일락 가디건, 민트 의상도 같은 아바타를 편집해 생성했다.
- 헤어 메뉴는 장발의 4가지 색상을 선택한다. 얼굴과 피부는 헤어 색상 변경에서 제외한다.
- 이미지로 렌더한 스프라이트를 사용한다. 회전 가능한 실시간 3D 모델은 아니다.

## 파일과 제작 방식

최종 서비스 자산은 `public/art/`의 WebP 20개이며, SVG 안에 이미지 레이어로 배치한다.
가구의 위치·뒤집기·키보드 이동·소품 추가 기능은 유지한다.
PNG 저장 시에는 모든 이미지 레이어를 data URL로 포함해 외부 참조가 사라지지 않도록 한다.

생성에는 내장 imagegen을 사용했다. 최종 생성 프롬프트 전체는 `art-prompts.json`에 보관한다.
원본 PNG와 원본 경로 기록은 로컬 `outputs/art-direction/`에 보관한다.
`scripts/prepare-art.mjs`는 PNG를 리사이즈하고 알파를 보존한 WebP로 인코딩한다.
실행하려면 sharp 패키지를 사용할 수 있어야 하며, 필요하면 `SHARP_MODULE`에 그 모듈 경로를 지정한다.
