# 나의 취향방 로고

2026-10-20. 사용자 요청에 따라 기존 상단의 ‘나루와 취향들’ 이미지를 ‘나의 취향방’ 커스텀 한글 타이포그래피로 교체했다.

‘나의’와 ‘취향방’을 두 줄로 묶고, 기존 타이틀의 경쾌한 글자 각도와 별 모티프를 이어갔다. 방 꾸미기를 나타내는 작은 집과 창문, 나루의 바다를 나타내는 곡선 밑줄을 더했다. 파스텔 블루·라일락·핑크·크림과 회청색 외곽선으로 웹사이트의 차분한 색상과 맞췄다.

## 조사 참고

Behance에서 `retro`, `y2k`, `logo`, `typography` 키워드로 검색했다.

- [Y2K Logotype Bundle](https://www.behance.net/gallery/216848589/Y2K-Logotype-Bundle): 레트로 로고의 굵은 글자 구성과 외곽선 처리 방향 참고.
- [BOOY2K / Lookbook & Graphic](https://www.behance.net/gallery/123466163/BOOY2K-Lookbook-Graphic): Y2K 타이포그래피·브랜드 그래픽의 결합 방향 참고.

해당 프로젝트의 글자·도형 파일은 다운로드하거나 사용하지 않았다. 사용자가 제공한 기존 타이틀을 브랜드 관계의 참고로 사용하고, 내장 imagegen으로 새 한글 로고를 생성했다.

## 결과 파일

- `public/brand/taste-room-logo.png`: 투명 배경 PNG.
- `public/brand/taste-room-logo.webp`: 웹사이트에 사용하는 투명 배경 WebP.
- `docs/logo-prompt.json`: 최종 생성 프롬프트.

데스크톱 표시 너비는 220px, 모바일은 172px다. 원래 타이틀 파일은 보존했다.
